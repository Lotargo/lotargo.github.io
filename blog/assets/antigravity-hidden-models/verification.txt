Источники этой сводки: сохранённая матрица native model/reasoning от 19 октября; отчёт Tab preview от 21 октября; отчёт проверки выделения SDK от 21 октября; отчёты Python SDK 0.2.0 и native 2.25.0. Это пересказ выбранных наблюдений. Приватные ссылки, исходный код SDK, бинарники, журналы авторизации и данные аккаунта сюда не включены.

Наблюдение о небольшом видимом изменении квоты относится к опыту автора. Контролируемого замера расхода подписки и подтверждения внутренней политики тарификации нет. Счётчики model-step usage не равны полному расходу аккаунта; в editor RPC токены не сообщались, а image-маршрут включал текстовый planner. Нулевой usage, безлимит и конкретная сумма экономии не установлены.

Сравнение Pro и Ultra по скрытым моделям в этой серии не выполнялось. Перечень доступных моделей и права аккаунта могут изменяться. Все модели и размеры в таблице относятся к датам соответствующих проверок.

## English

This is an editorial summary of retained observations used in “Antigravity's Hidden Models.” Preparing the article did not involve new model requests.

| Date | Conditions | Observation | Limit of the result |
| --- | --- | --- | --- |
| 2026-10-19 | Windows, native 2.23.1, text-agent matrix | gemini-3-flash returned a schema-validated result; selected and engine-reported model identities matched | A text check, not an OCR benchmark |
| 2026-10-19 | Same conditions | gemini-2.5-flash, gemini-2.5-flash-lite and gemini-2.5-flash-thinking passed the text contract | Does not establish quality for arbitrary tasks or future availability |
| 2026-10-19 | Same catalog | Some IDs returned RETIRED; gemini-2.5-pro returned capacity 503 | Catalog presence is not successful inference; a temporary capacity error does not prove permanent retirement |
| 2026-10-21 | Windows, native 2.24.0, Go SDK 0.2.0, plain text without tools | tab_flash_lite_preview and tab_jump_flash_lite_preview returned 391 for 17 × 23 | Short individual probes; not classifier-quality evaluation |
| 2026-10-21 | Windows, native 2.24.0, extracted SDK | Gemini 3.8 Flash correctly identified four colored quadrants in a synthetic PNG | Image-input control, not comparative OCR research |
| 2026-10-21 | Same build, native image tool | A 1024 × 1024 JPEG of a blue cup with a yellow triangle; response identified gemini-3.1-flash-image | Generation is confirmed; reference-editing fidelity was not measured |
| 2026-10-21–23 | Windows, native 2.24.0 and 2.25.0, Python and Go SDKs | Native diffs and jump positions were obtained; filtered and incorrect suggestions also occurred | Protocol functionality does not guarantee useful suggestions |

The retained sources are the October 19 native model/reasoning matrix, October 21 Tab preview report, October 21 SDK extraction validation, and Python SDK 0.2.0 and native 2.25.0 validation reports. This page summarizes selected observations. It contains no private links, SDK source code, binaries, authorization logs or account data.

The observation of little visible quota change is the author's experience. There is no controlled measurement of subscription consumption or confirmation of internal billing policy. Model-step usage counters are not total account consumption; editor RPCs did not report tokens, and the image route included a text planner. Zero consumption, unlimited access and a particular savings amount have not been established.

No hidden-model Pro-versus-Ultra comparison was performed in this series. Model lists and account entitlements may change. Model identities and dimensions in the table apply to the respective check dates.
