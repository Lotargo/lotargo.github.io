# Скрытые модели Antigravity

Список в agy и IDE показывает лишь часть возможностей движка. За селектором остаются старые Gemini, служебные Tab-модели и отдельный генератор изображений.

Я сделал SDK на Python и Go, который обращается к нативному движку без запуска agy и позволяет использовать эти возможности в собственных приложениях.

**Что это даёт**

• **Старые Gemini** интересны для распознавания текста, изображений и извлечения данных. Gemini 3 Flash продолжала отвечать в наших проверках.
• **Tab-модели** умеют отвечать и вне редактора. Их можно исследовать как компактные классификаторы и маршрутизаторы.
• **Изображения и редактор**: генерация, автодополнение и переходы по коду уже проверены. Качество редактирования по референсу ещё предстоит оценить.

**Из моделей можно собрать пайплайн**

Документ → распознавание → классификация → проверка полей → сохранение.

Или: задание → генерация изображения → анализ результата → уточнение задания.

Каждая модель выполняет свой этап, а приложение проверяет ответы и обрабатывает ошибки.

**Экономика одной подписки**

Pro стоит около $20 в месяц. За этой суммой стоит набор возможностей, для которых иначе пришлось бы подбирать отдельные сервисы и API.

В экспериментах некоторые служебные вызовы почти не меняли видимую квоту. Точный расход установить не удалось, поэтому особый учёт системных вызовов пока остаётся гипотезой. Обещания безлимита здесь нет.

Pro и Ultra влияют на модели и лимиты. SDK позволяет перечитать каталог аккаунта и проверить доступ после смены тарифа. Отключённую сервером модель он не восстановит.
